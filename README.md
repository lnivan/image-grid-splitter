# Image Grid Splitter

A Tkinter utility that splits an image into a 4×4 grid for poster printing.

## What it contains

- A native file picker and sixteen numbered image tiles.
- Remainder pixels are included in the final row and column.

## Setup

Use Python 3.12. From the repository folder:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python divisor_imagenes.py
```

## Project status

Requires Python with Tkinter. Output is written next to the selected image in a new folder.
